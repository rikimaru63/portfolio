## 2. 主張と証拠（節の順）
1. 裏方の仕組みを作る開発者である → 留まる題字「裏方」の下を、実物の画面が通る（hero）
2. AI は返信を書かず、承認済み定型文を選ぶだけ → その場で触れる振り分け実演（live）
3. 作った物は 8 つある → 名前の索引、中央の枠に画面（work）
4. 頼めるのは 4 つ → 4 枚の札（features）
5. 進め方は 5 動詞 → 動詞が留まる全面パネル（how-it-works）
6. 値段は切符に書いてある → 切符（pricing）
7. 連絡はメール 1 行 → 表示サイズのアドレス（contact）

## 4. 着想
On this page, **Ando の仕組みが持ち主に見せている画面（LINE の振り分け記録・入金表・EC の一括更新・毎朝の 1 枚）** becomes **留まる題字「裏方」の下を通る肖像**。
競合（他のフリーランス開発者）を入れると成り立たない: 通る画面がその人の物ではないから。
Live thing: LINE 振り分けの実演（打った文を分類し、承認済み定型文を選ぶか人へ回す。実際の分類の種類と定型文を使う。スマホで親指で動く。script 無しでは定型文の一覧が見える）。

## 決めたこと・redraw
- 配色・書体は配られたまま（薄紅 #edccbe / 茄子紺 #351a2b、Red Hat Display 900 / Red Hat Text）。和文は Red Hat に字形が無いので Zen Kaku Gothic New を当てる（3 家族目。必要なので弁明可）。
- features の「留める」は外す（留めるのは hero と work の 2 か所まで。motion 規則 8）。札の扇は配置として残す。
- how-it-works の全面写真は無い（撮れない）。全面パネルは 2 色の面にし、各段の実物（3 行の依頼、起こした仕様、影運用の記録、公開、引き継ぎ資料）を UI 断片で置く。
- live（振り分け実演）を hero の直後に足す。主張 2 の証拠。
